# A股上市公司智能财务分析系统

输入股票代码或公司名称，一键生成涵盖**财务指标、异常检测、审计分析**的综合报告。

## 功能

- **50+ 财务指标** — 盈利能力、偿债能力、营运能力、成长能力、现金流质量五大维度
- **杜邦分析** — ROE 三因素分解（净利率 × 资产周转率 × 权益乘数）
- **本福特定律检验** — 对营收、净利润、总资产、应收账款、存货做首位数字分布检验
- **异常检测** — Z-Score 时间序列突变检测 + 应计利润质量分析
- **Altman Z-Score** — 破产风险评估
- **审计视角分析** — 持续经营评估、收入确认风险、资产减值信号、报表勾稽检查、关键审计事项预判
- **综合健康度评分** — 0-100 分，五维度加权
- **HTML + Excel 报告** — 含雷达图、趋势图、杜邦图、本福特图

## 快速开始

### 安装依赖

```bash
pip install akshare pandas numpy scipy matplotlib openpyxl fastapi uvicorn
```

### CLI 使用

```bash
python main.py 600519        # 股票代码
python main.py 贵州茅台      # 公司名称
```

### Web 界面

```bash
python web_app.py
```

浏览器打开 `http://localhost:8765`，在搜索框输入代码或名称即可。

| P1 | 同花顺 (THS) | 财务指标摘要，作为补充 |
| P2 | 东方财富 (East Money) | 公司基本信息 |
